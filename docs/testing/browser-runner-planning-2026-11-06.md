# Planning/entity/execution migration audit

Baseline reviewed: 68 Chromium scenarios across 22 feature files, from 9b02e21f. Every loop-expanded original title appears below. All client assertions use the existing missionHarness and native Vitest Browser controls; in-memory remounts establish rehydration only.

Native paths below are under `src/tests/vitest-browser/behavior/`; retained paths are under `src/tests/playwright/behavior/`.

Validation: 31 new native tests pass in isolated sequential targeted runs (port15321, cache-planning, one Chromium worker) (including the final Maestro completion display contract: 1 test, 622ms test body /14.29s total). Owned targeted ESLint passes. Central root validation runs full gate and retained Playwright. Timings below are development runs with concurrent agents, not benchmark claims: first12 tests34.18s(cold optimizer), folder/metadata5 passing, stationGraph+itinerary+folder visibility11 tests35.99s(warm optimizer), execution values/status2 tests20.93s(warm optimizer).
