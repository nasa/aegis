- Native targeted runs at `VITEST_BROWSER_PORT=15322`, cache `.local/migration/cache-map`, Chromium workers1. Initial npm shell forwarding mistake used default worker count once; excluded from benchmark evidence.
- Initial6 native tests:5 pass,1 matcher failure; fixed native visibility matcher. Later targeted native30:29 pass,1 vector fixture-path failure; fixed absolute transport fixture path.
- Final location/style/lifecycle targeted rerun:4 files,10 tests pass;34.43s warm-cache wall,18.34s test bodies. Earlier position/map navigation/circle/lifecycle targeted run supplied29 other passing tests. Central final validation/benchmark supersedes these development timings.
- Original measurementTerrain four scenarios passed native, including UI mission switch with held response. Final benchmark and retained integration checks coordinated centrally by root.
- Geometry cancel distance equality uses `expect.closeTo(value,10)` only for IEEE roundoff (~3e-15m) after actual cancel recomputation; every other station field and path remains exact.
- Canonical vector/asset data now comes from shared `tests/playwright/fixtures/layerStyleSeed.ts` in both runners. No test uses a new app harness, mocked operations, locator adapter or document mutation to perform asserted local geometry/control interactions. Existing real components/Redux/Automerge/OL and shared mission seeds are reused.
